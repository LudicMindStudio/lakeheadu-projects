## Digital Mental Health Technology Decision Framework (domains, questions, recommended actions; comparable to D3SM toolkit)

This aspect of the website is for educators, students, and other stakeholders to evaluate the safety and utility of different digital mental health technologies. It should prompt questions for each domain and topic and, at the end of each domain, provide guidance.

Type of technology

- mHealth app
- Chatbot
- Social media
- Forum or group chat
- Others tbd

Quality of technology

- Credibility
- Evidence
- Safety
  - E.g., Chatbots → "Chatbot has a human-in-the-loop safeguard" Y/N → if Y, proceed with caution, if N, recommend MHCC-certified chatbot
- Privacy
- Presence of persuasive design features
- Others tbd

User considerations

- Awareness of risk
- Knowledge of available recourse options
- Age/vulnerability
- Presence of adult supervision during time online
- Extent of online engagement

## Searchable Digital Mental Health Technology Resources and Tools Database

This is a database that will index reliable sources of information about and readily applicable tools for digital mental health technologies. Filters indicate options for only showing entries that belong to selected categories, such as only showing videos. Sorting criteria are values by which users can rank-order entries, such as by showing the most recently published entries first.

Filters

- Libraries
- Lesson plans
- Videos
- Podcasts
- Organizations and websites
- Articles (non-research)
- Articles (research)
- Tools (e.g., checklists)
- Age group
- mHealth apps (our library)
- MHCC mHealth directory
- MindApps.org

Sorting criteria

- Relevance to query
- Recency

## Searchable Mental Health Services Database (comparable: Pathways to Youth Wellness Website)

This is a database that will index the available mental health services in Northwestern Ontario. Filters indicate options for only showing entries that belong to selected categories, such as only showing in-person services. Sorting criteria are values by which users can rank-order entries, such as by showing treatment options that are closest to a user's location first.

Filters

- Cost (free, not free)
- Nature of resource
  - In-person
  - Group programming
  - Individual programming
  - Remote
  - Phone
  - Video call (individual)
  - Video call (group)
  - mHealth app
  - Text-based
- Self-referral
  - Yes
  - No
- Services are designed with special consideration towards:
  - Indigenous people
  - Women
  - LGBTQ+
- Age range
  - <18
  - 18-65
  - 65+
- I want help with:
  - Depression
  - Anxiety
  - Stress
  - Trauma
  - Sleep
  - Relationships
  - Substance use

Sorting criteria

- Relevance to query
- Location (closest → furthest)
- Cost (least → most)

Option for partner sites to log in and update details and availability of different services

E.g., put in info for what you need and everything Children's Centre Thunder Bay/St. Joe's/whoever has for that patient population appears including the first step/point of contact
